# IPIC asset provenance

Authored reconstruction of IPIC River Oaks, generated by
`preview/src/ipic-interior.js` from the pure plan in `ipic-plan.js`.
Source: 44 user-supplied photographs retained under `assets/ipic/references/`
with SHA-256 manifest. Generated concept previews are excluded.

`IMG_9771.jpg` and `IMG_9761.jpg` are unmodified original images. Mesh UVs
select the mural and floral artwork regions. All other finishes and geometry
are authored procedural approximations. `ipic-interior.glb` embeds the rendered
materials and these photographic texture selections. The user requested use
for this game; no public-domain or third-party redistribution license is
asserted for venue artwork or marks. See `docs/ipic-interior.md` for limitations.

Layout and dimensions are inferred, not surveyed. Eight auditorium seats are
an authored sample, not a statement about the real seating plan.
