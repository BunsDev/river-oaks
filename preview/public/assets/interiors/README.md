# Imagined retail interiors

`retail-atlas.png` is original AI-generated artwork created September 20, 2026 with the built-in image generation tool for this project. It depicts unbranded imagined retail back walls, not photographed River Oaks stores.

Quadrants: top left fashion; top right jewelry; bottom left dining; bottom right perfume/beauty. Runtime materials sample these quadrants as a framed feature wall at the rear of each walk-in room, and as the back wall of the remaining shallow alcoves between rooms. Everything else inside the rooms is procedural geometry from `src/store-interiors.js`.
