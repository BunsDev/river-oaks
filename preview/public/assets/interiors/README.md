# Imagined retail interiors

`retail-atlas.png` is original AI-generated artwork created September 20, 2026 with the built-in image generation tool for this project. It depicts unbranded imagined retail back walls, not photographed River Oaks stores.

Quadrants: top left fashion; top right jewelry; bottom left dining; bottom right perfume/beauty. Runtime back-wall materials sample these quadrants behind actual 3D storefront glazing, alcoves and props. These backdrops are flat artwork, not fully navigable interiors.
