# Reference Board

Turn references into spatial decisions someone can build and test.
Read the [shared working contract](../../../docs/level-design-skills.md#shared-working-contract)
and the target runtime notes when the location already exists in the game.

## Gather useful evidence

1. Establish the location's purpose, activities, users, era, and intended mood.
   Read the brief and existing map first. Preserve known footprints and entrances.
2. Collect a small, complementary set of real-world and game references. Favor
   plans, sections, eye-level approaches, occupied rooms, and gameplay views over
   multiple decorative images that teach the same thing.
3. Open and inspect each source you rely on. Record its URL or local path,
   creator/title, image or video timestamp, and access date. If browsing is
   unavailable, annotate supplied material and list missing research explicitly.
   Do not invent source URLs or imply an unseen image was inspected.
4. Explain what each reference teaches about **layout, materials, scale, and
   mood**. State what transfers to this location and what does not. A cinematic
   game shot can teach mood without proving ordinary gameplay readability.
5. Tie scale estimates to visible anchors or published dimensions. Label lens
   distortion, unknown camera height, and uncertain dimensions. Keep ranges when
   a single number would imply false precision.

## Reference card

Use one card per distinct reference, with a thumbnail or linked frame when you
can retain it under the source's terms:

| Field | Include |
| --- | --- |
| ID and source | `REF-01`, real-world/game, attribution, locator, access date |
| Layout | Entrances, circulation, activity pockets, and sightlines |
| Materials | Surface role, roughness, wear, joints, and human-scale detail |
| Scale | Anchor, dimension/range in meters, and confidence |
| Mood | Light, contrast, density, and emotional intent |
| Apply | Specific spatial decision and where to use it |
| Avoid | Misleading perspective, incompatible use, or non-transferable detail |

Prefer links and attribution when redistribution rights are unclear. A reference
image is not permission to ship its artwork, mesh, or texture.

## Synthesize and hand off

Resolve conflicting references against the brief and mapped constraints. Produce
a compact board or Markdown contact sheet plus a short design brief: anchors to
preserve, intended route, activity zones, key proportions, and open questions.
Separate observed facts from proposed game adaptations.

The board is ready for **Blockout Builder** when each major layout decision has
an evidence source or a labeled assumption. Missing dimensional evidence can
remain an assumption; missing core layout intent needs resolution before building.
