> Execution: implement inline, using failing-first regressions, then whole-branch review.

Goal: prevent new visible depth conflicts from hiding behind #695's known classes and correct focused interior overlaps without changing the designs.

Architecture: build on #695 head `3d666a2982b1c422f1ad7e1d0acde9dc3b8d13e8`; keep diagnostics outside the render loop. Preserve both existing increments and their corrected shared-frame gap measurement. Use a separate branch `fix/depth-review-hardening-20261027`.

Constraints: plain JavaScript ESM / Three 0.186.1; pnpm 10.34.5; no global camera, shader, fidelity or performance-policy changes; no changes to authoritative collision, identity or movement. Do not duplicate the owner's incorporated facade, roof-cap or paving fixes.

## Tasks and interfaces

1. Audit extraction (`preview/src/depth-layer-audit.js`, corresponding tests): test transformed/hidden/deleted batched instances and their actual geometry ranges; distinguish instance colours on shared materials; preserve ordinary identical-material suppression only when appearance is equivalent. Test world-space output under parent transforms and draw/group clipping. Preserve model thresholds.
2. Regression gate (`preview/e2e/depth-layers.js`, new pure baseline helper/tests): bind exemptions to spatial/directional occurrences with bounded counts and area/width, reject moved/enlarged/duplicated conflicts, and reject additions in burn-down mode before any write. Establish the new occurrence snapshot from the unmodified geometry baseline and record its exact construction/verification scope. Add the missing batched room-clip rendering case.
3. Focused geometry (`preview/src/store-interiors.js`, `preview/src/ipic-interior.js`, focused tests): prove mirror/backing and reception overlap before changing geometry. Recess backing or trim duplicate faces without changing silhouettes/materials/colliders. Record any candidate that cannot safely be corrected without further visual evidence.
4. Verification/delivery: focused regressions, full preview suite/build and core gate, named depth browser journey; compare budgets before/after. Publish an isolated draft follow-up PR and comment on #695. No merge or deployment is authorized by this implementation request.

Review focus: sparse batch IDs and hidden geometry; nonidentity parent transforms; shared-material colours/UV differences; multiple same-class locations and occurrence growth; intentional transparent layers and hidden undersides.
