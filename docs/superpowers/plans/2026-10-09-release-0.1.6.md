# TypeSafe Place 0.1.6 release

## Objective and authority

The user asked to cut v0.1.6 using the documented desktop release process (as for
0.1.5): version bump PR merged with the guard, a detached release worktree on the
merge commit with its own `npm ci`, tests and packaging there, a signed tag and a
GitHub release. Branch `release/v0.1.6` (bump only), on `22d0043`.

## Scope since v0.1.5 (`9b25e18`)

- #187: modernized district login and connection screen; the hosted town migrates
  saved checkpoints across the public facade-height edits instead of rejecting
  saved town admission.
- #191 (Codex): storefronts and paving matched to Street View references (gray stone
  strip paving, Cartier corner), Hopdoddy's photo-aligned trees.
- #190: 0.1.5 release receipts (docs only).

- [ ] Production deployment of the merge commit.
- [ ] `ditto` zip, SHA-256, `unzip -t`, re-extracted signature; signed tag on the merge

## Limits

Ad-hoc signed, not Apple notarized. Packaged-mode sign-in is interactive, so live
authenticated play is not verified; human accessibility, Windows/Linux and native
Unreal packaging are not verified.
