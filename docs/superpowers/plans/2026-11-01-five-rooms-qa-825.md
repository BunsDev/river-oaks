## Design decisions

- **Spawn frame without a contract.** The budget frame is the arrival spawn looking at
  `walkLookAt` (district.json), at sharp graphics, 1280×800, DPR 1, noon. It needs no contract,
  so the baseline is measured on main (`--pin=baseline`) and the same frame on the integrated
  head (`--pin=integrated`, and the journey's own check).
- **Budget rule.** No 657 constant exists in code (#825 corrected facts). The budget is the
  classic spawn frame measured on main plus 15 % headroom, rounded up; the pin records head,
  camera, preset, viewport and both finishes' counts. The pin validator refuses a budget that is
  not derived from its measured baseline, so the threshold cannot be lowered or raised by hand.
- **Pink rule review.** At night (19:00, the client's latest hour) each view is scanned for lit
  pink clusters (hue 290–352°, saturation ≥ 0.3, value ≥ 0.42, ≥ 6 px at 320×200). Each cluster
  is picked through `__riverRenderAudit.pick`; the hit's object, path and material decide
  usable / landmark / violation. Unresolved picks (sky, sprites) are listed, not passed. This is
  an agent heuristic; the packet says so.
- **Compact receipts.** `assertCompact` refuses any 40–64 hex string and any per-file map, so no
  raw sha256 map reaches a receipt (gitleaks reads them as generic API keys).
