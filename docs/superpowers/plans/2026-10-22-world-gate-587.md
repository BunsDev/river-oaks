## Changes

- **Location label:** the walking HUD names River Oaks District / East Garden Commons, and the polite live region announces each crossing once. Default and Gardens revisions are unchanged.
- **Error-panel reload:** a "Reload world data" button appears only for a world-data load failure, takes focus, and is hidden when a reload starts. Walking mode hides the panel `#reload`, so keyboard players previously could not recover.
- **Journey `preview/e2e/world-gate-587.js`:** two-client, keyboard-only. Covers failed-manifest self-heal, a failed data load with keyboard reload, accessible names, collision probes, sync tolerance, in-Commons reconnect, five crossing loops with renderer counts, return home, live-region announcements, twenty rebuilds and fixed-view screenshots.
- **Audit `preview/audit/world-gate-587.js`:** matched Gardens vs Commons performance on desktop and phone-sized viewports.
