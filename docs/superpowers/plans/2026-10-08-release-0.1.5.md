# TypeSafe Place 0.1.5 release

## Objective and authority

The user asked to cut v0.1.5 using the documented desktop release process: version
bump PR merged with the guard, a fresh `npm ci` in a detached release worktree on the
merge commit, tests and packaging there, a signed tag, and a GitHub release.
Branch `release/v0.1.5` (bump only) in `.worktrees/river-oaks/release-bump`, on `79e391f`.

## Scope since v0.1.4 (`2020849`)

- #181: busy actions keep their HUD slot and focus; only keyboard focus pins an
  action; Commands search opens tabs before rail toggles; doorway and map refusals
  never show bare codes; one Stand up control; one share sheet at a time, accurate
  photo quality details and slider names.
- #184 (Codex): full doorway clearance in boutique room plans.
- #185: the town notice no longer shows bare travel refusal codes.
- #186: a meet refused by the travel cooldown says to wait instead of "no clear place".
- #188: photo mode does no per-frame detail work; dead HUD code and CSS removed.
- #180, #182, #183, #185: test and CI reliability (shared journeys, Mesa CI for the
  contextual, photo and command journeys, three journeys updated for the shared town).

## Plan and checks

- [ ] Bump PR: `npm version patch --no-git-tag-version` (package.json and lockfile only),
      desktop tests, signed commit, guard merge.
- [ ] Release worktree detached on the merge commit with its own `npm ci` (not the
      primary checkout's linked `node_modules`).
- [ ] `npm test`, `npm run test:server`, `npm run test:desktop`, `npm run build`,
      `npm run desktop:package`, desktop e2e with the loopback acceptance fixture.
- [ ] Package integrity: `codesign --verify --deep --strict`, version 0.1.5 in the app.
- [ ] Production deployment of the merge commit (the app loads the hosted game).
- [ ] `ditto` zip, SHA-256, signed annotated tag on the merge commit, GitHub release
      with zip and `SHA256SUMS`; uploaded digests match local.

## Limits

Ad-hoc signed, not Apple notarized. The packaged app loads the hosted game after
WorkOS device sign-in; packaged-mode sign-in cannot run unattended, so live
authenticated play is not verified. Human accessibility, Windows/Linux and native
Unreal packaging are not verified.
