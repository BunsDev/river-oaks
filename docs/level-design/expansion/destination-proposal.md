# Proposed first destination: East Garden Commons

The user approved this destination through native input with “Approve East Garden Commons”. It remains a design contract; implementation and acceptance status are tracked in [the blockout report](blockout-builder.md). It preserves the District, Gardens, gallery and interiors, and adds original Houston-inspired content in the east-side coordinate reservation. The [source-and-proposal map](destination-proposal.svg) distinguishes existing geometry, the current resident boundary, the first-slice envelope and the larger empty reservation.

The first slice is a 70 × 80 metre envelope centred at east −2586.336078522973, north −1335. A roughly 99 metre promenade connects from a player-clear point at east −2685, north −1335 through the existing east edge. This is a proposed centreline, not proof of continuous clearance, slope, accessible travel or a measured walking time. Local terrain height near the existing eastern walkway is approximately 18.35 metres; the new ground must meet the real edge height and slope without moving District terrain.

The destination provides a shaded social plaza, an original garden pavilion as the landmark, a landscaped rain garden, benches and a two-player table activity. Reuse the established ivory, teal, brass, rose and mint material language and licensed asset pipeline. The table activity should extend existing server-authoritative table/seating systems with new stable entity IDs, preserving existing District games and checkpoints. The pavilion is an authored fictional building, not a model of a real business or private residence.

Start with the playable connection and gathering place, then extend streets and modular buildings within the reserved area. The 5,600 m² first-slice envelope does not satisfy the overall 3–5× reachable-area objective; it is the first end-to-end checkpoint. The entire east reservation covers 147,506.25 m² of bounding area and is not yet playable.

Acceptance requires a continuous two-player walk from District arrival to the commons, a completed shared activity, and a return without reload; a disconnect/reconnect; safe failed-load behavior; stable character and camera state; bounded chunk resources; collision and route verification; and matched visual/performance review. Resident routing must handle the existing 80,000-cell cap through bounded location routing instead of simply enlarging its single grid. Keep one authoritative shared session unless measured need justifies partitioning.

Destination decision: East Garden Commons approved. Continue implementation, playable review and measurement under the existing world-expansion mission. Approval of the concept is not proof of geometry, multiplayer, performance or visual acceptance.
