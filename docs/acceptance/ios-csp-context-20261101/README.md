# Controlled CSP context evidence, 1 November 2026

These are actual unsigned Debug iPhone 17 / iOS 27.2 simulator observations using a synthetic bundled page and loopback HTTP witness. [The qualified comparison](qualified-comparison.json) pins the native/probe inputs, app-file hashes and current source-policy digest. Source paths are relative to `experiments/ios-bundled-origin`. The [policy input](source-csp.txt) is copied byte-for-byte from the trial. This is a controlled measurement, not production, actual Capacitor, HTTPS-cookie, real-client or physical-device qualification.

| Policy | Page-world fetch | Isolated-world fetch | Simple module worker |
| --- | --- | --- | --- |
| Disabled control | HTTP 200, witness request | HTTP 200, witness request | Nonce-matched replies in both worlds |
| Current source CSP | TypeError, matching connect-src canary event, no witness request | HTTP 200, witness request | Nonce-matched replies in both worlds |

The page canary rejection is supported by error type, matching CSP evidence and independent witness traffic. Abort errors and missing/mismatched CSP evidence are rejected as inconclusive. Document-level CSP events were visible to both listeners, including the isolated listener whose own fetch succeeded; event presence alone cannot attribute request rejection to a world. The tested surface was trusted native instrumentation; these results do not authorize a new native interface or imply untrusted-page privilege escalation.

This finding corrected the ordinary experiment: [control](page-poll-control.json) and [CSP-enabled](page-poll-csp.json) runs now execute in the page world and report `resultTransport: native-poll`, zero registered handlers and one navigation. The CSP-enabled witness fetch fails with connect-src events. Both integrations produced 15 observations without forged markers; these are observations, not 15 passed original-host acceptance criteria. The ordinary mode's policy remains the archived snapshot, explicitly separate from the current-source comparison above.

This establishes that graceful case only; synchronous commands can delay signal handling, and forced-kill cleanup is unqualified.
