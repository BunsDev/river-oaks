# TypeSafe Place 0.2.2

0.2.2 is the first release for Windows and Linux as well as macOS. Windows gets a Squirrel installer and Linux gets an AppImage and a `.deb`; all of them are built and install-tested on fresh CI runners. The Windows installer is **not code-signed** in this release. Val chose on 2026-10-27 not to hold the release for the Azure Artifact Signing setup (#372), so Windows SmartScreen will warn that the publisher is unknown. The macOS app stays Developer ID–signed and notarized, as in 0.2.1.

## Windows and Linux

- **Windows x64** (`TypeSafe-Place-0.2.2-windows-x64-Setup.exe`). Squirrel installs per user into `%LocalAppData%\TypeSafePlace`, with no administrator prompt, and adds Start menu and desktop shortcuts. It also adds an Installed apps entry that uninstalls cleanly. The `.nupkg` and `RELEASES` files are what a later updater reads; nothing downloads them yet (#372, #399).
- **Unsigned on Windows.** SmartScreen shows "Windows protected your PC". To install, choose **More info**, then **Run anyway**. Check the file's SHA-256 against the release's `SHA256SUMS` first. Signing is wired in CI and turns on once the Azure account exists (#372).
- **Linux x64.** The `.deb` installs the app with a desktop entry and icons. It sets up Chromium's sandbox helper (`chrome-sandbox`, root 4755) and installs an AppArmor profile so the sandbox works on Ubuntu 23.10 and later. The AppImage runs without installing. On Ubuntu 23.10 and later it is expected to stop with Chromium's sandbox message unless an AppArmor profile allows it; `docs/desktop.md` explains why and what to do.
- **Linux crash recovery.** When the game's renderer crashes on a system with `systemd-coredump`, the app ends the crashed process instead of waiting for the core dump. It then reloads in seconds rather than minutes (#653).

## macOS

Signed with Developer ID and notarized as in 0.2.1. The packaged app gains only the two modules above: the Windows installer hook, which does nothing on macOS, and the Linux core-dump watch, which runs only on Linux. Electron moves from 44.7.0 to 44.9.1 for its security fixes.

## Hosted game since 0.2.1

The desktop app is a thin client of the hosted game, so these arrive through the server, not this download. The headline changes on `main` since 0.2.1:
- **World.** The Bayou Market Commons and the Bayou Heights districts. Residents can walk anywhere in town, and vehicles drive wherever they fit (#584–#586).
- **Play.**
  - A server-owned world clock and danger zones.
  - Melee with wanted stars, and police pursuit and arrest (#596–#598, #640).
- **Garden Offices.** Suites by lease, suite desks and public workstations (#505, #510, #512).
- **IPIC.** A 3× auditorium wing and a second screening film (#498–#502).
- **Safety.** Player blocking enforced by the server, and moderator review of saved reports (#292). In-app account deletion ships switched off.
- **Resilience.** Clearer behaviour when the network drops mid-action, recovery after backgrounding, and in-place graphics recovery (#290). On phones, touch holds for looking while walking and push-to-talk (#288).

## Compatibility

- **Upgrading on macOS.** Replace the app in Applications. Cookie encryption is unchanged from 0.2.1, so you stay signed in.
- **Windows and Linux** have no earlier release, so there is nothing to upgrade from.
- **Rollback.** Reinstall 0.2.1 on macOS. On Windows, uninstall from Installed apps. On Linux, `sudo apt remove typesafe-place` or delete the AppImage.

## Not claimed

- A signed Windows installer, and any change in SmartScreen reputation.
- Linux on distributions other than Ubuntu LTS, ARM builds of either, and iOS or Unreal distribution.
- Human accessibility review and quiet-machine 60 Hz acceptance. These stay gated as in 0.2.1.
