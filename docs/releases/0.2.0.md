# TypeSafe Place 0.2.0 — release candidate

This candidate adds shared procedural building levels and World Studio authoring.
It is prepared from main `489a60e4` and the reviewed #349–#358 interior stack,
ending at `0bcf539e`. It has not been merged, tagged, published or deployed.

## New since 0.1.6

- World Studio building and furnished-space templates, local drafts, import/export,
  native desktop menus and optional explicit designer tasks. Generated building
  levels now expose shell, partition, fixture, finish and authored-override layers.
- Stable furnishing and floor-finish edits, previewed regeneration of untouched
  levels, and validated publication of generated creator regions.
- A two-level public gallery pilot with server-approved plans, authoritative
  transitions, reconnect recovery and occupancy-aware detail streaming.
- Expanded shared plaza games and guided lessons, nearby social interactions and
  shared voice, plus the office arrival and photo-guided IPIC interior.
- Places guide, expandable minimap, updated chat/settings and diagnostic reporting.
- Access-revocation, retention, collision, checkpoint and performance hardening.
- Server support for shared café dominoes with private hands and checkpoint
  recovery; the shared-game interface is a separate follow-up.

## Compatibility and rollout

- The procedural level protocol is version 3 and district checkpoints are version 7.
  Deploy the matching browser and server together. Existing supported district
  checkpoints use the explicit migration paths; preserve a checkpoint backup and
  the previous application revision before any production rollout. Do not downgrade
  a version-7 checkpoint into an older server or relax digest validation.
- Existing unconverted storefronts and creator packages retain their existing
  behavior. Furnished Studio documents open as level 0 without rewriting saved bytes.
- The pilot's compact vertical route is an instantaneous platform-lift transition;
  it is not a walkable stair flight or an animated lift ride.
- Acceptance is scoped to this Mac with Chromium, as selected by Val. Auto quality
  can reduce ambient occlusion to recover frame pacing. Sharpest keeps AO and can
  miss the 60 Hz budget during repeated gallery movement. Wider device/building
  rollout remains gated; no universal frame-rate claim is made.

## Desktop distribution

The macOS arm64 package is a thin client that loads the hosted game. Installing
the candidate alone does not deploy its browser/server changes. Local packaging
uses the existing ad-hoc signature and hardened Electron fuses. Developer ID
signing, notarization and live packaged sign-in remain separate release gates.
No Windows, Linux, iOS or Unreal distribution is claimed by this candidate.

## Release decision

See the [readiness ledger](../superpowers/plans/2026-10-14-release-0.2.0-readiness.md)
for exact checks, artifact hashes, remaining acceptance and the final publication
sequence. Val accepted the retained Auto-quality gallery capture for this limited
pilot. That image review and automated fixtures do not establish live production
authentication or human keyboard/accessibility acceptance.
