# TypeSafe Place 0.2.0

0.2.0 is `main` as merged through PR #376. It adds shared procedural building levels, World Studio authoring, the Office and IPIC visit, and connection and performance hardening. The candidate was first cut on 2026-10-14 from main `f72a89f8` (the reviewed #349–#358 interior stack and the #382 contact-shading pilot). It was refreshed on 2026-10-15 onto current `main`, which takes in the further pull requests merged since (#384–#439); the [readiness ledger](../superpowers/plans/2026-10-14-release-0.2.0-readiness.md) records the exact head. Merging it moves `main` to 0.2.0. No tag, package publication or separate deployment is part of this change.

## New since 0.1.6

### Procedural levels and World Studio
- World Studio building and furnished-space templates, local drafts, import and export, native desktop menus and optional explicit designer tasks.
- Generated building levels expose shell, partition, fixture, finish and authored-override layers.
- Stable furnishing and floor-finish edits, previewed regeneration of untouched levels, and validated publication of generated creator regions. Required routes survive edits, undo and reopen (#427).
- A Garden Office realism pilot, with its forms and lighting (#439).
- A two-level public gallery pilot with server-approved plans, authoritative transitions, reconnect recovery and occupancy-aware detail streaming.

### Office and IPIC
- **Office.** Resident-owned office computers with private and shared tasks (#390). Desk footprints come from the approved kit's measurements (#430).
- **Penthouse** (behind `RIVER_OAKS_OFFICE_LAYOUT=office-penthouse-1`; the legacy office stays the default):
  - a versioned office layout (#396);
  - server-authoritative floors, stair and lift (#397, #434);
  - seat claims with occupied-body clearance (#400);
  - bounded views and the scene-idea prompt (#404);
  - the glazed curtain wall and skyline (#405, #408, #426, #433);
  - the tower raised to 33 m (#432).
- **IPIC.** The photo-guided interior with route and seat evidence (#402, #419, #424).
- **Screenings.** An authoritative screening timeline with host controls (#395); synchronized playback, captions and recovery (#398, #407); and the approved original short as the default screening (#429). Hosting stays off until `RIVER_OAKS_SCREENING_HOSTS` names a host.
- **Games.** Shared darts in the IPIC Tuck Room (#412), and the unbranded Axe & Darts room with shared axes and darts (#415).

### Play, people and interface
- Expanded shared plaza games and guided lessons, nearby social interactions and shared voice, the office arrival, the Places guide, the expandable minimap, updated chat and settings, and diagnostic reporting.
- Server support for shared café dominoes, with private hands and checkpoint recovery. The shared-game interface is a separate follow-up.
- On phones, the nearby greetings card no longer covers Play & rides or Commands (#425).
- The landing page offers residents who already have access a direct way in (#437).

### Connections and performance
- A 30-second reconnect grace on the standalone server (#384 asserts it).
- Access-revocation, retention, collision, checkpoint and performance hardening, and office persistence recovery (#394, #410).
- Fewer repeated cloth-contact calculations. The sampled gown geometry and rendered poses are identical.
- Inside the IPIC auditorium the frame draws only IPIC. Every culled frame is pixel-identical, and the seated view went from 555 to 99 draw calls (#431, #435).
- A performance profile for Office and IPIC on this Mac (#428).

### Desktop
- Desktop packaging builds on Windows, Linux and macOS in CI (#377).
- Studio prompts pass on stdin (#391).

## Compatibility and rollout

- **Versions.** The procedural level protocol is version 3. Town checkpoints are written as **version 11**, and versions 2–10 are read and migrated. Deploy the matching browser and server together.
- **Rollback.** Keep a checkpoint backup and the previous application revision. Do not run a version-11 checkpoint on an older server. Roll back by configuration on the current writer: the legacy office layout, and no screening hosts.
- **Building raise.** The penthouse tower raise (#432) changes the world fingerprint. The first Redis load migrates the town checkpoint across it. A saved flight that the taller roof would enclose fails closed, so land any flight over the tower before deploying (`docs/offices.md`).
- **Unchanged content.** Existing unconverted storefronts and creator packages keep their behavior. Furnished Studio documents open as level 0 without rewriting saved bytes.
- **Gallery pilot.** The pilot's compact vertical route is an instantaneous platform-lift transition, not a walkable stair flight or an animated lift ride.
- **Acceptance scope.** Acceptance is scoped to this Mac with Chromium, as selected by Val.
  - Auto quality uses the approved floor and wall contact shading inside generated pilot rooms, and restores the district's AO policy after exit.
  - Sharpest keeps full GTAO and can miss the 60 Hz budget during repeated gallery movement.
  - Wider device and building rollout remains gated, and no universal frame-rate claim is made.

## Desktop distribution

The macOS arm64 package is a thin client that loads the hosted game. Installing it does not deploy browser or server changes. Local packaging uses the existing ad-hoc signature and hardened Electron fuses. Developer ID signing, notarization and live packaged sign-in remain separate release gates. CI builds Windows and Linux packages, but no Windows, Linux, iOS or Unreal distribution is claimed by this release.
