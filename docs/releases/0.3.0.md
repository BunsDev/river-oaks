# TypeSafe Place 0.3.0 (proposed)

**Proposed; not tagged. Qualification result on `a42b3835`: BLOCKED.** Warmed performance,
the 20-loop streaming resource bound and graphics-recovery listeners regressed against v0.2.2,
partly from #708. This is a candidate under qualification. The candidate commit, the
gate evidence and the GO/BLOCKED recommendation are in the
[release ledger](../superpowers/plans/2026-11-02-release-v030.md). Tagging, publishing and
deploying are Val's decisions.

0.3.0 is candidate `a42b3835`. It collects the 106 pull requests merged to `main` after
`v0.2.2` (`f4dd959a`, 2026-10-27), including the two fixes qualification added (#866, #867).

**Pink Jet-Age is the default look on the candidate.** #831 made it the default, and it landed
under Val's merge authorization for the Five Rooms stack on 2026-11-02. Classic stays available
as an explicit, reversible override (URL or saved preference). The goal started with Classic as
the default, so Val confirms this before tagging; see the ledger's "Decisions for Val".

## Compatibility

- **Default look:** Pink Jet-Age, with Classic as an explicit override (#831). Val confirms
  this before tagging.
- **Rollback needs a backup.** Back up the town's room keys before deploying 0.3.0, because a
  rollback to `v0.2.2` means restoring that backup. A plain code rollback fails closed: v0.2.2
  refuses every join with 1013 ("Town temporarily unavailable"). That happens because 0.3.0
  saves checkpoint version 18 (#708) against new world data, and v0.2.2 reads neither. Restoring
  the backup brings v0.2.2 back with the pre-deploy town, and anything players changed after the
  deploy is lost. The upgrade itself carries positions and chat over. Both paths were rehearsed
  on disposable local services, on the default and Gardens revisions, with
  `scripts/release/rollback-rehearsal.mjs`. The release ledger has the receipts.
- **Desktop:** the packaged app changes with Electron 45. Signing, notarization and real-machine
  acceptance follow the [desktop release steps](../desktop.md#releases-on-windows-linux-and-macos)
  and are Val's.
