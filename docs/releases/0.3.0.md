# TypeSafe Place 0.3.0

**Merged to `main` and deployed on 2026-11-11 by the owner's decision. Qualification is not a GO.**
The owner creates the `v0.3.0` tag and the GitHub release; see the release ledger.

- The last pinned qualification run (`3a20dfa1`, 2026-11-10, recorded on #359) is BLOCKED on one
  row: phone-viewport one-player CPU submission p95 is 9.60 ms against 8.70 ms on v0.2.2, +10.34%
  against the unchanged +10% budget. Its cause is unassigned. Every other row was within budget.
  No budget was waived and nothing was rerun for a pass; the owner chose to release with the row
  open.
- Two changes landed after that run and are not performance-qualified: the original District's
  Pink Jet-Age materials (#915) and the retirement of the saved Classic choice (#914). Both
  change colour or a preference read only.
- Nobody has reviewed the restyled District in the running game. See "Not claimed".

first candidate was `a42b3835` (106 pull requests, including #866 and #867); most sections below
describe it. "Since the first candidate" lists what landed afterwards. The earlier gate evidence

## Compatibility

- **Look:** Pink Jet-Age for every visitor. A saved Classic choice is ignored (#914). The
  `?finish=classic` address parameter remains for test harnesses until #913 removes it, along
  with the Classic material tables that are still in the code.
- **Rollback needs a backup.** Back up the town's room keys before deploying 0.3.0, because a
  rollback to `v0.2.2` means restoring that backup. A plain code rollback fails closed: v0.2.2
  refuses every join with 1013 ("Town temporarily unavailable"). That happens because 0.3.0
  saves checkpoint version 18 (#708) against new world data, and v0.2.2 reads neither. Restoring
  the backup brings v0.2.2 back with the pre-deploy town, and anything players changed after the
  deploy is lost. The upgrade itself carries positions and chat over. Both paths were rehearsed
  on disposable local services, on the default and Gardens revisions, with
  `scripts/release/rollback-rehearsal.mjs`. The release ledger has the receipts.
- **Desktop:** no 0.3.0 desktop build is published with this release. The packaged app changes
  with Electron 45; the macOS build, signing, notarization, installer collection and
  real-machine acceptance in the [desktop release steps](../desktop.md#releases-on-windows-linux-and-macos)
  were not run. Pushing the `v0.3.0` tag starts the `Desktop` workflow, whose installers are
  unaccepted candidates, not release assets.
